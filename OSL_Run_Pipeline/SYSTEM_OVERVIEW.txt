================================================================================
SCRIPT OVERVIEW: webcam_inference_osl.py
================================================================================

CLASSES AND FUNCTIONS:

1. Config class
   - Project paths (PROJECT_ROOT, UNISIGN_DIR, etc.)
   - Model parameters (ISLR task, 64 frames, etc.)
   - Inference settings (min frames, confidence threshold, smoothing)
   - Webcam settings (resolution, FPS)
   - validate() method for configuration checking

2. ModelLoader class
   - Imports Uni-Sign model registry
   - Creates ISLR model architecture
   - Loads checkpoint from disk
   - Handles different checkpoint formats
   - Moves model to GPU/CPU
   - Sets evaluation mode

3. LabelLoader class
   - Reads Words.txt label file
   - Maps ID -> word text
   - Returns dictionary for label lookups

4. PoseExtractor class
   - Initializes MediaPipe Holistic detector
   - extract() method: Extracts 261-feature pose vectors
   - draw_on_frame() method: Visualizes skeleton on video
   - close() method: Releases resources

5. InferenceEngine class
   - Loads model and labels
   - predict() method: Runs inference on pose sequences
   - Pads/trims sequences to 64 frames
   - Returns top-K predictions with confidence

6. WebcamApp class (main application)
   - Initializes all components
   - open_webcam() method
   - run() method: Main loop
   - Handles keyboard input (space, R, C, Q)
   - Display status, predictions, FPS
   - _handle_recognition() method
   - cleanup() method

7. main() function
   - Argument parser (--device option)
   - Configuration validation
   - App instantiation and execution
   - Error handling

KEY FEATURES
================================================================================

✅ POSE EXTRACTION
   - 33 body landmarks: head, shoulders, elbows, wrists, hips, knees, ankles
   - 21 left hand landmarks: fingers, palm, wrist
   - 21 right hand landmarks: fingers, palm, wrist
   - Total: 261 features (3 coordinates per landmark)

   - Maintains buffer of last 64 frames

CONFIGURATION PARAMETERS

Can be modified in Config class:

  MAX_SEQUENCE_LENGTH = 64         (frames per sequence)
  MODEL_TASK = "ISLR"              (task type)

Inference:
  MIN_FRAMES_TO_RECOGNIZE = 5      (minimum frames to run inference)

  SMOOTHING_WINDOW = 3             (past predictions to track)

  WEBCAM_WIDTH = 640               (resolution)
  WEBCAM_HEIGHT = 480
  WEBCAM_FPS = 30

MediaPipe:
  MP_DETECTION_CONFIDENCE = 0.5    (pose detection sensitivity)
  MP_TRACKING_CONFIDENCE = 0.5     (pose tracking stability)

Paths (must point to your installation):
  PROJECT_ROOT = Path(r"C:\Users\MOBPC\Downloads\FYP\FYPproject")

  CHECKPOINT_PATH = ... / "best_checkpoint.pth"

================================================================================
KEYBOARD CONTROLS
================================================================================

SPACE   → Start/stop recording a sign sequence
          First press: begin recording
          Second press: stop recording (shows frame count)

R       → Run recognition on recorded sequence
          Requires ≥5 frames
          Displays top-5 predictions with confidence

C       → Clear current sequence buffer
          Resets for next sign
          Stops recording if active

Q       → Quit application
          Closes webcam window
          Releases all resources
          Graceful shutdown

Alt+F4  → Force close (if needed)

================================================================================
INPUT/OUTPUT
================================================================================

INPUT:
  Source: Webcam (30 FPS)
  Format: RGB video frames (640x480)
  Processing: Pose keypoint extraction
  Model input: 64 frames × 261-dimensional feature vectors

PROCESSING:
  1. Extract pose landmarks using MediaPipe Holistic
  2. Buffer frames in sliding window (0-64 frames)
  3. When user presses R:
     - Pad/trim sequence to exactly 64 frames
     - Convert to torch tensor
     - Run model inference (1 forward pass)
     - Extract top-5 predictions
     - Map IDs to word labels

OUTPUT:
  Display: Live webcam with skeleton overlay
  Console: Top-5 predictions with confidence scores
  Screen overlay: Status, last prediction, instructions

Example output:
  🔍 Recognizing 52 frames...
  
  ✅ Top-5 Predictions:
     1. hello                (88.4%)
     2. hi                   (7.2%)
     3. good                 (2.8%)
     4. morning              (1.3%)
     5. thanks               (0.3%)

INTEGRATING WITH YOUR PROJECT
================================================================================

The script is designed to work standalone:

1. Paths are hardcoded but can be edited in Config class
2. No external dependencies except PyTorch, OpenCV, MediaPipe
3. Works with your trained checkpoint directly
4. Uses your Words.txt labels automatically

To integrate:
1. Copy webcam_inference_osl.py to your project
2. Run install_dependencies.py
3. Execute python webcam_inference_osl.py

To customize:
1. Edit Config class for different paths
2. Modify keyboard controls in WebcamApp.run()
3. Add logging/saving in _handle_recognition()
4. Adjust pose visualization in draw_on_frame()

☐ Labels loading correctly?
  Check first few lines of Words.txt (format: "1 hello")

☐ Model loads?
  Check console output for model loading messages

☐ Pose detected?
  Check if MediaPipe draws skeleton on webcam (hands should show lines)

☐ Inference works?
  Try with minimum 30 frames for better results
